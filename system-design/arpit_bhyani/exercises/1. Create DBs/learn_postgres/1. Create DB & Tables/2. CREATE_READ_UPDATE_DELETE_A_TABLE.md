1. Create a Table:
    ```
        CREATE TABLE person(
            id INT,
            name VARCHAR(100),
            city VARCHAR(100)
        );
    ```

2. Describe schema of the table, columns and their respective datatypes:
    ```
        \d person;
    ```

3. Inserting data in tables
    The sequence of columns after table name and the sequrnce of values/tuples should be same.

    String should be wrapped in single quotes.

    ```
        INSERT INTO person(id, name, city) 
        VALUES (101, 'Sailesh', 'Cuttack');
    ```

4. Inserting Multile rows in a single query:
    ```
        INSERT INTO person(id, name, city) 
        VALUES 
            (101, 'Sailesh', 'Cuttack'),
            (102, 'Patra', 'Cuttack')
    ```

5. If you're inserting values in every column of the table, you can even skip mentioning the column names after db name in insert-query. In such scenarios, the sequence of the data tuples should match with column sequence in table schema.

    ```
     INSERT INTO person
        VALUES (101, 'Sailesh', 'Cuttack');
    ```
6. You can choose to insert data into few specific columns of the table. In this scenario, for rest of columns of that particualr row, NULL will be inserted.

```
    INSERT INTO person (id, name)
        VALUES (101, 'Sailesh');
```

### Read data:
1. select * from person;
2. select name from person;
3. select name,city from person;

### Updating a table:

```
update person
    set city="London"
where 
    id=2;
```

### Delete data from a table
```
DELETE from person
where id = 104;
```

### Show all tables in a DB:
```
\dt
```

OR

```
SELECT table_name 
FROM information_schema.tables 
WHERE table_schema = 'public';
```
