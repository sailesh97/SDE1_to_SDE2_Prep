### Databases

#### 1. List down existing databases:
    ```SQL
    SELECT datname from pg_database;
    ```

    or

    ```
    \l
    ```

#### 2. Create a Database:
Name of database is case-insesitive.

Which means USER === user.

If there's a table already exists with name USER, you can't create a new DB with "user"
```
CREATE DATABASE <db_name>;
```

#### 3. Change the active database:

You've 3 database: User, Followers, Following

Followers is the active DB and you want to switch to User:

```
\c <db_name>;
```

#### 4. Drop a database

```
DROP DATABASE <db_name>;
```
