1. WHERE clause:
    ```
    select * from employees where emp_id=5;
    ```
2. WHERE clause + Relational operators
    ```
    select * from employees where salary >= 50000;
    ```
![alt text](./1.relational_operator.png)

3. LOGICAL Operator AND:
    WHERE clause + Relational operators + Multiple conditions attached using logical operators:
        
        ```
        select * from employees where salary >= 50000 AND dept = 'IT';
        ```

4. Logical Operator:
    - AND
    - OR
    - IN
    - NOT IN

5. LOGICAL Operator IN: 
Sometimes attaching multiple conditions using `AND` can be cumbersome. We can use `IN` operator in such scenarios:
```
select * from employees where dept IN ('IT', 'FINANCE');
```

Without `IN` you can achieve the same usecase like:

select * from employees where dept = 'IT' or dept = 'HR';

6. LOGICAL Operator BETWEEN: To find a range

```
select * from employees where salary b
etween 50000 and 60000;
```
