Complex queries with multiple table joins can be hard to think and write.

You can think once and save the queries as Views so that you don't have to type it out everytime:

Syntax:

-> Create a view
CREATE VIEW NAME_OF_VIEW AS
SELECT coulmsOfTable1, columnsOfTable2 from table1 join table2 groupby ...;

-> Get all columns from a view:
SELECT * from NAME_OF_VIEW;

-> Describe a view
\dt

-> You can even do grouping aggregations on Views.


-> Qs: after creating a view, if there's some new row inserted in db, will it show in same view?
Ans: Yes. For a normal PostgreSQL view, newly inserted/updated rows will show up automatically if they satisfy the view's query conditions.
