4 ways to connect to VM:
1. EC2 Instance Connect
2. Session Manager
3. SSH Client
4. EC2 serial console

#### How to connect using SSM ?
Just go to this tab and click Connect

--> How to switch to a root user?
    sudo su
-> whoami -> Who's the active logged in user?
-> ping 8.8.8.8 (Google's IP Address)
whoami will return "ssm-user" here.

#### How to connect using EC2 Instance Connect?
Connection Type: "Connect using EC2 Instance Connect" -> Selected by default, No need to change

Public IPv4 address - Selected by default, No need to change

Username: "ubuntu" (It's added by default), No need to change

Click on Connect

---> whoami will return "ubuntu" here

#### Note:
In the above two methods, we're connecting to the terminal of VM from AWS console itself. But what if you want to connect to this VM from your laptop remotely, without logging in to AWS Console???????
Ans: Use SSH Client method.
