Not normally. If you run:

```bash
docker run nginx
```

Docker attaches the container's output to your current terminal. The terminal is therefore **occupied by the running Nginx process**.

You may see something like:

```text
/docker-entrypoint.sh: ...
nginx: ...
```

and your prompt won't return.

### If you want to keep using the same terminal

Run the container in **detached mode**:

```bash
docker run -d nginx
```

`-d` = detached/background mode.

Now you'll immediately get your shell prompt back:

```bash
$ docker run -d nginx
abc123...

$ docker ps
```

You can continue running commands in the same terminal.

### If you already ran `docker run nginx`

You have a few options:

**Option 1 — Open another terminal**

Leave Nginx running and use another terminal window/tab.

**Option 2 — Stop the container**

Press:

```text
Ctrl + C
```

This stops the attached Nginx container and returns you to the prompt.

**Option 3 — Run it detached from the beginning**

```bash
docker run -d --name my-nginx nginx
```

Then, if you want to see its output:

```bash
docker logs my-nginx
```

And if you want to enter the running container:

```bash
docker exec -it my-nginx bash
```

No — **`exit` does not always stop a Docker container.** It depends on **what process you're exiting**.

### Case 1: `docker run -it nginx bash`

```bash
docker run -it nginx bash
```

You are running `bash` as the **main process** of the container.

```text
Container
└── bash  ← PID 1
```

If you type:

```bash
exit
```

Bash terminates → the main process terminates → **container stops**.

```text
exit
 ↓
bash stops
 ↓
container stops
```

---

### Case 2: `docker exec -it my-nginx bash`

Suppose Nginx is already running:

```bash
docker run -d --name my-nginx nginx
```

Then:

```bash
docker exec -it my-nginx bash
```

Now Bash is **not the main process**.

```text
Container
├── nginx  ← main process (PID 1)
└── bash   ← started by docker exec
```

If you type:

```bash
exit
```

only the **Bash shell closes**.

```text
exit
 ↓
bash stops
 ↓
nginx keeps running
 ↓
container keeps running
```

You can verify:

```bash
docker ps
```

The `my-nginx` container will still be running.

### The rule to remember

> **A container runs as long as its main process (PID 1) is running.**

So:

| Situation                           | `exit`                  | Container       |
| ----------------------------------- | ----------------------- | --------------- |
| `docker run -it ubuntu bash`        | Stops `bash`            | 🛑 Stops        |
| `docker exec -it my-container bash` | Stops `bash`            | ✅ Keeps running |
| `docker run -d nginx`               | You're not inside shell | ✅ Keeps running |
| `docker stop my-container`          | —                       | 🛑 Stops        |

**Think of `docker exec` as "temporarily enter the container."** Exiting that shell doesn't mean you're stopping the container.
