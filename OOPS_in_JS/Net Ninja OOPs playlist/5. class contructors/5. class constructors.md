- constructor functions constructs a new object of the class,
- We create objects of a class using a new keyword
    ```
    var userOne = new User(email);
    ```

    ```
    class User{
        constructor(email) {
            this.email = email;
        }
    }
    ```
- What does a `new` keyword do?
    - creates a new empty object in memory and sets `this` to the new empty object created.
    - Inside the class wherever you access this, it will point to the empty object.
    - calls the constructor method.
    - Explanation: 
    When code inside constructor method runs and we say `this.email = email`, here this will refer to the new empty object created.
