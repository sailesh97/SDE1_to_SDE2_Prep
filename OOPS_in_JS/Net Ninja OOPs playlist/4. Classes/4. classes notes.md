To reduce the redundant code, we can do something like:
```
var userFour = new User(params);
```

By this we can pass dynamic parameters and create objects in just one line.
This is the class syntax.

- We can create a class in multiple ways.
    - Using prototypes
    - Using classes, a es6 syntax which is a syntactic sugar on top of prototypes.

Lecture 4 is about classes. Will learn prototypes later.

Syntax:
```
class User{}
```

class keyword and name of class with capital first letter as a convention.
