- Objects have properties and things they can do (methods).
- Explained using devtools.

```
var names = ['ryu', 'crystal', 'mario'];
```
The above returns an expandable value in devtools, with all properties & methods available for an array.

### Null
- Not everything is an object is javascript, ex: null
- null type isn't expandible in devtools

### Primitive Types
- There are other types such as Numbers, Booleans, Strings which are called Primitive Types. **Even though they're not objects, they behave like an object**.
- Even though you can't expand and see methods and properties for these in devtools, you can call those methods & properties.
- `var name = "Sailesh"` is same as `var name = String("Sailesh")`. The later syntax will return an expandible object in devtools.
- `var name = "Sailesh"` internally calls String wrapper function and attches the methods & properties to `name` variable.

#### There're builtin objects in JS like `window` but you can create your own objects as well in JS.
