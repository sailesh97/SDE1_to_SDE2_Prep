Create an object to store related data & functionality

```
var userOne = {
    email: 'ryu@ninjas.com',
    name: 'Ryu',
    login: function(){
        console.log(this.email, 'has logged in');
    }
};
```
or
```
// ES6 syntax
var userOne = {
    email: 'ryu@ninjas.com',
    name: 'Ryu',
    login(){
        console.log(this.email, 'has logged in');
    }
};
```

`Note: If you're adding a functions inside a object and accesing this inside the function, this will point to object it lives in`
