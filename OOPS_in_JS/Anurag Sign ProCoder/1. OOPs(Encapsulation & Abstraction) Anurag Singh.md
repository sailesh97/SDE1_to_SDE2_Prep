Takeaways of Episode 80:
- Demerits of factory functions:
    functions are created for each user created from factory function
- array1.pop === array2.pop // true
Because, pop is added to arrays using prototypes.

- Without prototypes, using factory function also there's a workaround to solve the issue:
```
function getBirthYear(){
 // new Date().getFullYear() - this.age;
}

function createUser(firstName, lastName, age){
    return {
        firstName, 
        lastName,
        getBirthYear,
    }
}
```
- In above snippet, all users created from createUser function will point to same function in memory.
- But it's not following encapsulation & abstraction(hiding the complexity) now.  

Workaround to solve above: (Encapsulation is not fixed, but Abstraction is fixed)
```
function createUser(firstName, lastName, age){
    return {
        firstName, 
        lastName,
        getBirthYear: createUser.commonMethods.getBirthYear
    }
}
createUser.commonMethods = {
    getBirthYear(){
        return new Date().getFullYear() - this.age;
    }    
}
```
